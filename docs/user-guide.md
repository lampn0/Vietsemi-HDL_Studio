# Vietsemi HDL Studio user guide

How to work with HDL Studio day to day: projects, libraries, the editors and generation.
Installation is in the [README](../README.md); the design of the tool in
[architecture.md](architecture.md).

Start the tool from the repository root:

```
python bin/hdlstudio.py                     # Design Manager, reopens the last session
python bin/hdlstudio.py path/to/project.hdp # open a project directly
python bin/hdlstudio.py --new               # start empty
python bin/fsm_editor.py [file.sm]            # the state diagram editor on its own
```

A sample project is in `examples/uart_studio/uart.hdp` (a UART built with HDL Studio).

## Tasks

| Task | How to do it |
|---|---|
| Open an existing project | File > Open Project (`.hdp`), or File > Recent Projects. Libraries are grouped into Regular/Protected. Errors such as an unset variable or a missing folder are shown in red and in the Log |
| Create a new project | File > New Project: name, location, default library. Creates `<name>/<name>.hdp` and `<lib>/hdl`, `<lib>/hds` |
| Add a library | File > New Library. It is written to the `.hdp` file in the same format as the old tool |
| Browse a library | Double-click a library. You get 3 panes: **Design Units** (Component/Module, language, time stamp, views), **Files** (red = parse error), **Design Hierarchy** (expandable, with generate blocks `FOR : x`; a unit that is not found is shown in red). Select a unit to see the hierarchy below it |
| Create a design unit | File > New Design Content: **State Machine**, **Block Diagram**, **SystemVerilog module** or **Verilog module**, choosing the language of a graphical view (Verilog 2005 / SystemVerilog) and entering the port list |
| Edit an FSM | Double-click the view. A state diagram read from a legacy `.sm` is **written back into that `.sm`** (only what was edited changes, so the legacy tool and HDL Studio edit the same file; the unit's `symbol.sb` follows when the ports change). A state diagram created in HDL Studio is saved as `hds/<unit>/<view>.fsm.json` |
| FSM diagram | Four toolbars as in the legacy editor: **Standard** (New, Back, Forward, Open Up, Save, Print, Document & Visualize, Cut, Copy, Paste, Undo, Redo, Find, Object Properties, Expression Builder, zoom), **State Diagram Tools** (Select, Text, Panning, Clock, Reset, Recovery, Enable, State, Transition, Interrupt, Link, Junction, Hierarchical State, Wait State, Panel), **HDL Tools** (View Generated HDL, Run Design Rule Checks) and **Tasks** (Check, Registers, Generate, Simulate, Synthesize, each with its Run ... drop-down). View > Toolbars shows or hides each one and turns the tool tips off. A button is greyed when it has nothing to act on (Cut/Copy without a selection, Paste with nothing copied, Clock when the machine has one, Back/Forward at the ends of the window history). The condition/action box has a **line between the condition and the actions** and can be dragged anywhere. **Drag a transition line** to create a bend point, drag the dot at either end to change where it attaches to the state, double-click a bend point to remove it. The state action box (en/in/ex) can also be dragged. When drawing a new transition, click empty space to add bend points |
| Edit a block diagram | Saving writes `hds/<unit>/<view>.bd.json` next to the `.bd`; the legacy `.bd` is read, not written back yet (see [roadmap.md](roadmap.md)). **Drag** a component, embedded block or port (legacy rules): everything attached moves with it — nets, dangling net connectors and the ports at the other end of its nets — except nets going to another component or embedded block, which stretch and stay horizontal/vertical (10-unit grid). Port icons touch their nets. **Nets:** drag a net to move it (ends on pins/ports stay), **Alt+drag** moves one segment, a selected net shows square handles to drag its route points, Shift constrains to horizontal/vertical. **Connect by dragging:** drop a free port on a net connector and it connects and takes the net name; drop a dangling net end on a port (or a free pin) and it connects, the net taking the port name. **Double-click a net** to edit its name in place (`name[7:0]` changes bus bounds); Enter applies, Esc or clicking elsewhere cancels. Net names are shown where the legacy diagram put them. **Right-click a net / port** gives the legacy popup menus (Add Route, Remove Route, Remove All Routes, Add Port I/O, Goto Destination, Disconnect, Highlight Net, Change Style, Show Text, Comments, Object Properties / Change Mode, Show Text, Disconnect, Object Properties; simulation and appearance entries are greyed). Toolbar: **Add Component (C)** (pick a library.unit from the project), **Add Signal (S/F7)** / **Add Bus** (click where the net starts, click where it ends: a component port, a port, an embedded block, an existing net (joined with a dot) or open space; named `sig0`, `dbus0`... or after the component port, never asked), **Add Signal/Bus with a Port**, **Input/Output/Inout Port (I/O)** (a faded port follows the cursor; with its wire end on a net end, a net or a component port it connects and takes the net's name; in open space it has no name until connected), **Embedded Block (E)** (double-click it: Create Embedded View > Text; the white Text view moves and resizes on its own), Delete, rename a net (double-click the net, or F2 for a dialog). Edit instance parameters and the embedded block code in the Properties panel. **Open Down** (Ctrl+D or double-click an instance) opens the sub-module |
| State diagram commands | **Cut / Copy / Paste** states, junctions, links and points with the transitions between them (also between windows). **Edit > Align / Distribute** line the selection up on the object selected first. **Expression Builder** builds a condition from the signals and operators and puts it on the selected transition. **Add > Input / Output / InOut Port, Local Signal** (F8 / F9 / F11) add a row to the Signals Table; **Add > Concurrent State Machine** (Ctrl+F2) adds a machine, **Diagram > Open Machine / Delete Machine / Rename Concurrent Machine** switch between, remove and rename machines. **Add > Hierarchical State** and **Wait State**; double-click a hierarchical state (or File > Open > Down) to edit its inside (it gets an entry and an exit point), Open Up goes back. **Diagram > Change To** State / Junction / Link keeps the transitions. **Add > Comment Text** puts a free text on the diagram (double-click to edit). **Diagram > Reverse Direction**, **Copy Picture** (selection or whole diagram to the clipboard), **File > Print... / Print Window...**, **View > Snap to Grid / Object Tips** |
| Find and Replace (both diagrams) | **Edit > Find... (Ctrl+F) / Replace... (Ctrl+H)** open the legacy *Find and Replace* dialog: **Find** and **Replace** tabs, *Find What* (the last searches are kept for every window), **Find Next** (the text opens in place with the match selected in blue, a comment text has the match marked on the diagram; *Select related object* selects its object instead; after the last match: "End of search. Hit 'Find Next' to start again.", nothing at all: "Search completed. Nothing was found."), **More >>** for the options: *Search Depth/Direction* (current diagram), *Search selected objects* (select kinds such as State name, Transition conditions, Signal Name, Signals Name Column to search only those; **Clear Constraints** searches all again), *Match case*, *Match whole word only*, *Wrap search*, *Regular expression* (`\1` in Replace With is group 1; **Reg. Exp. Syntax** shows the syntax). **Find All** lists the matches in a table below (Diagram, Object Name, Status, Text; double-click a row to go there), **Select All** selects their objects, **Replace** changes the match found and goes to the next, **Replace All** changes them all as one Undo step. A state renamed keeps its links; a net renamed is renamed everywhere |
| Signals Table / Parameters Table | Spreadsheet pages laid out exactly as the legacy tool: the column order and widths, the frozen columns, the row order, the header / cell / group colours and the format of single cells (alignment, colours, bold) are read from the legacy `.sm` / `.bd` (its Sheet), a new diagram gets the legacy defaults (frozen Group, Name, Mode). Column letters (A, B, ...) above the names; the frozen columns stay at the left when the table scrolls sideways; the current row and column tinted yellow. While a table page is shown the window has the legacy table menus (**Table**: Copy Picture, Compiler Directives, Export TSV / CSV, Ports > Comments, Group, Columns > Sort / Hide Column / Show Columns, Autofit, Filter, Filter Settings, Toggle Signals/Parameters Tables, Show Grouped, State Machine Properties; **View > Table for machine / State Machine**; **Add** Input / Output / InOut Port, Local Signal, Group), a shorter Standard toolbar, **SM Signals Tools** (Add Input / Output / Inout Port, Add Local Signal, Group, UnGroup, Expand / Collapse All Groups, **Toggle Filter**: a filter row under the column names with a drop-down per column, **View Table for Machine**, Autofit, Sort in ascending / descending order, Toggle Show Grouped, Switches between Signals/Parameters Tables) and, at the bottom, **Appearance** (Foreground Color and Font Color: the legacy 5 x 5 colour grid and Other..., Fill Style, Increase / Decrease Font Size, Bold, Italic, Underline, Align Left / Center / Right, for the selected cells). State diagram signals: Group, Name, Mode, Type, Signed, Bounds, Delay, Value, Category (Data, Clock (Rising / Falling), Reset (Async High / Low), Enable (High / Low): picking one also writes the expression), Assign In (<auto> / <none>), Expression, Scheme (Comb / Clocked / Registered, N/A when not assigned), Default, Reset, Comment; block diagram signals: Group, Name, Mode, Type, Signed, Bounds, Delay, Value, Comment; parameters: Group, Name, Value, Comment. Cells that do not apply are grey and cannot be edited. Type in a cell to edit it (choices in a drop-down list), Enter goes down; type in the empty last row to add a signal; Del clears cells or deletes the rows selected by their numbers; Ctrl+C / Ctrl+V copy and paste cells as tab-separated text. Column widths, the row order and cell formats are saved with the diagram (HDL Studio file); a legacy `.sm` keeps its own table layout |
| Both diagrams | **Add > Panel** marks a named area (dark red frame): **View > View Panel** zooms to it, **Diagram > Panels** deletes, prints, protects (cannot be moved) or renames / resizes it (Object Properties). **Edit > Paste Special > Paste from system clipboard** puts the clipboard text on the diagram as a comment text. **File > Document And Visualize > Single Level** writes an HTML page (picture of the diagram and the generated HDL) to a folder you pick and opens it. Comment texts and panels are kept in the HDL Studio files (`.fsm.json`, `.bd.json`); a state diagram saved back to a legacy `.sm` warns that they are not written there |
| Block diagram commands | The same Standard / HDL Tools / Tasks toolbars, and **Block Diagram Tools** (Select, Text, Panning, Highlight Net, Clear Net Highlighting, Block, Component, ModuleWare, External IP, Embedded Block, Frame, Signal, Bus, Bundle, Port, Global Connector, Panel, Edit as IBD, Visualize as IBD). **Align / Distribute**; **Add > Comment Text**; **Diagram > Autoroute > Connect By Name** (free ports of the selected components, or of all, get a stub on the net or port of the same name); **Edit as IBD / Visualize as IBD** list the connectivity, one row per net (driven by / connects to), and Edit as IBD renames a net by editing its name; **Open Up** goes to the diagram that instantiates the unit (the one Open Down came from first); **Copy Picture**, **Print...** |
| Right-click in a block diagram | **Component:** Open Down, Cut/Copy/Paste/Delete, **Add Signal Stubs** (a named net on every unconnected pin), **Add PortIO** (a module port for every unconnected pin), Disconnect, Equidistant Ports, **Update Interface** (re-read ports from the HDL), **Generics/Parameters...** and **Object Properties...** (Library / Component / Instance name, parameter list with Add, Add All, Remove, Clear, show parameter values). **Wire/port:** Object Properties (type, signed, vector and array bounds, initial value, delay, expansion, trireg charge strength, comment), Rename. **Empty space:** Paste, Add Component/Port/Embedded block. **Add Component** has a **From HDL file (.v/.sv)** button that reads the ports and parameters straight from a file |
| FSM extras | Each condition/action box and state action box has a **dashed line** to its owner (red when selected). The **priority number** can be dragged along the transition. Closing a modified window asks **Save / Discard / Cancel** |
| Shortcuts (legacy defaults) | Taken from the legacy Graphical Editors manual. Common: **Shift+G** generate, **Ctrl+G** view generated HDL, Ctrl+S, Ctrl+Z/Ctrl+Y, Ctrl+A select all, Del/Backspace, **Alt+Enter** object properties, **F2** edit text/rename, **Home** view all, **Shift+Home** view area, **Shift+Up/Down** zoom, **Ctrl+arrow** move the selection one grid step, **Esc** back to Select. State diagram: **F3/S** state, **Shift+F2/H** hierarchical state, **F4/L** link, **F7/T** transition, **F8/W** wait state, **I** interrupt, **J** junction. Block diagram: **Ctrl+F3/B** block, **F3/C** component, **F4/E** embedded block, **F7/S** signal, **Shift+F7/U** bus, **Ctrl+F7/N** bundle, **F8/I** input port, **F9/O** output port, **F11/T** inout, **F5/G** global connector, **F6 / Shift+F6 / Alt+F6** FOR / IF / ELSE frame, **Ctrl+F10** signal stubs, **Shift+F10** stubs + PortIO, **Shift+Alt+C** disconnect, **Ctrl+D** open down. Commands not built yet are greyed out but keep their keys reserved |
| Commands (legacy behaviour) | Every menu item and toolbar button uses the legacy name, tooltip and status-bar description. **Add commands repeat** until Esc or the **right mouse button**; hold **Ctrl** while choosing one to add a single object. **View Area**: drag a rectangle to view it, then you are back in Select. **Zoom Last** returns to the previous zoom. **Panning**: left-drag moves the diagram until Esc. **Select / Select Text / Select Shapes** (state diagram: text = condition/action boxes). **Generate**: Single, Through Blocks (children in the same library), Through Components (every child with a graphical view), Through Design Root (from `design_root` in the .hdp) |
| Common to both diagrams | **Ctrl+Z / Ctrl+Y** undo/redo, Ctrl+wheel zoom, **Shift+wheel horizontal scroll**, middle mouse to pan. **Each view remembers its zoom and position** when reopened |
| Edit HDL text | Double-click a `.v`/`.sv` file: line numbers, find/replace, go to line, **syntax check with slang (F7)**. Click an error to jump to that line. You can switch to gvim/emacs in Options > Preferences |
| Generate | Ctrl+G in the editor, or select units in the Design Explorer and press Ctrl+G, or right-click a library > Generate whole library. The file goes to the library's `hdl` folder, named by the rule `%(unit).%(ext)` |
| Preferences | Default language (SystemVerilog), state declaration, encoding, file naming rule, **header template**, external editor |

## Session and unsaved work
- **Start-up and opening a project:** a splash screen with the Vietsemi logo shows what the tool is doing until the project is open. While a project opens and its libraries are scanned, the status bar at the bottom of the Design Manager shows the library and how many of its HDL files are read.
- **Reopen where you left off:** starting the tool (`python bin/hdlstudio.py`) reopens the last project, its library tabs and every editor window (place on screen, current tab, text cursor line). The session is kept in `~/hdl_studio/user/v2026.12/session.json` and updated as windows open and close. `python bin/hdlstudio.py project.hdp` opens that project (with its last windows if it was the last one); `--new` starts empty; Options > Preferences can turn this off.
- **Crash protection:** every 30 s, unsaved diagrams and HDL text are copied to `~/hdl_studio/user/v2026.12/autosave/`. The copy is removed when the editor is saved or closed normally. If the tool stopped abnormally, opening the view again asks whether to recover the unsaved changes.

## Protection
- **Edit lock:** opening a view to edit creates `<file>.lck` in the same format as the old tool. If someone else is editing, you can open it read-only or reset the lock. A lock you left yourself on this machine from a run that no longer exists (a crash, a killed tool) is taken over without asking, with a line in the Log.
- **Overwrite protection:** the tool asks before overwriting an HDL file that was edited by hand or generated by another tool.
- **Protected libraries** are always opened read-only.
